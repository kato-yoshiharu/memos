# Vim Commands

## カーソル移動

- [x] `h` / `j` / `k` / `l`: 左 / 下 / 上 / 右に1文字(1行)移動する
- [x] `w` / `b`: 次 / 前の単語の先頭に移動する
- [x] `e` / `ge`: 次 / 前の単語の末尾に移動する
- [x] `shift+w` / `shift+b` / `shift+e` / `g` + `shift+e`: 記号を区切りとみなさず、空白区切りで同じ移動をする
- [ ] `0` / `$`: 行頭 / 行末に移動する
- [ ] `^` / `g_`: 行の最初 / 最後の非空白文字に移動する
- [x] `f<char>` / `t<char>`: 行内の次の`<char>` / その直前に移動する
- [x] `shift+f` / `shift+t`: 同じ移動を後方に対して行う
- [x] `;` / `,`: 直前の`f`・`t`を同じ向き / 逆向きに繰り返す
- [x] `%`: 対応する括弧に移動する
- [ ] `(` / `)`: 前 / 次の文に移動する
- [ ] `shift+[` / `shift+]`: 前 / 次の空行に移動する
- [ ] `gj` / `gk`: 折り返された表示行の単位で下 / 上に移動する(`g0` / `g$`も同様)

## ファイル内の移動

- [x] `gg` / `shift+g`: ファイルの先頭 / 末尾に移動する
- [ ] `<n>gg`: n行目に移動する
- [ ] `shift+h` / `shift+m` / `shift+l`: 画面の上端 / 中央 / 下端の行に移動する
- [x] `ctrl+d` / `ctrl+u`: 半画面下 / 上にスクロールする
- `ctrl+f` / `ctrl+b`: 1画面下 / 上にスクロールする
  - `ctrl+d` / `ctrl+u`でカバー
- [x] `ctrl+e` / `ctrl+y`: 1行ずつ下 / 上にスクロールする
- [x] `ctrl+i` / `ctrl+o`: jump listを次に進む / 前に戻る
- [ ] `g;` / `g,`: change listを前 / 次にたどる
- `` `` ``: 直前にいた位置に戻る
  - 1回目は`ctrl+o`と同じ位置に戻るが、2回目以降は履歴を遡らず、2点間を往復する
  - `ctrl+o`は履歴を1つずつ遡る
  - `ctrl+o` / `ctrl+i`でカバー
- `''`: 直前にいた行の最初の非空白文字に戻る
  - `ctrl+o` / `ctrl+i`でカバー

## 画面のスクロール位置

- [ ] `zt` / `zz` / `zb`: 現在行が画面の上端 / 中央 / 下端に来るようにスクロールする
- `zh` / `zl`: 横に1文字ずつスクロールする(折り返しなしのとき)
  - `wrap`時は横スクロールがないので不要
- `zs` / `ze`: カーソル位置が画面の左端 / 右端に来るように横スクロールする
  - `wrap`時は横スクロールがないので不要
- `ctrl+l`: 画面を再描画する(表示が乱れたとき)
  - 頻度が低い

## 挿入モードに入る

- [x] `i` / `a`: カーソルの前 / 後ろから挿入する
- [x] `shift+i` / `shift+a`: 行の最初の非空白文字の前 / 行末から挿入する
- [x] `o` / `shift+o`: 下 / 上に空行を作って挿入する
- [x] `s`: カーソル位置の文字を消して挿入する
  - `cl`の短縮形
- [x] `shift+c`: カーソル位置から行末までを消して挿入する
  - `c$`の短縮形
- [ ] `shift+s`: 行の内容を消して挿入する
  - `cc`の短縮形
- [ ] `gi`: 最後に挿入していた位置から挿入する

## 挿入モード中の操作

- [ ] `ctrl+w`: 直前の単語を消す
- [ ] `ctrl+u`: この挿入で入力した分を消す
- [ ] `ctrl+r` + `<reg>`: レジスタ`<reg>`の中身を挿入する
- [ ] `ctrl+a`: 直前の挿入で入力した内容をもう一度挿入する
- `ctrl+v`: 次の入力をそのまま挿入する(`ctrl+v` + `u3042`でUnicodeを指定する)
  - 使わない
- `ctrl+k`: ダイグラフで特殊文字を入力する
  - 使わない
- [ ] `ctrl+n` / `ctrl+p`: 次 / 前の候補で単語を補完する
- [ ] `ctrl+x` + `ctrl+f` / `ctrl+l` / `ctrl+o`: ファイル名 / 行 / omniで補完する
- `ctrl+x` + `ctrl+]`: tagで補完する
  - 使わない
- [ ] `ctrl+t` / `ctrl+d`: 行のインデントを1段深く / 浅くする
- [ ] `ctrl+o`: 1回だけノーマルモードのコマンドを実行して挿入に戻る

## 編集

- [x] `x`: カーソル位置の文字を削除する
- [ ] `shift+x`: カーソルの前の文字を削除する
- [ ] `shift+d`: カーソル位置から行末までを削除する
- [x] `u` / `ctrl+r`: undo / redo
- [ ] `g-` / `g+`: 変更が起きた時刻順に前 / 後にたどる(枝をまたいで全履歴をたどれる)
- [ ] `:earlier 10m` / `:later 10m`: 10分前 / 後の状態にする(`:undolist`で分岐を一覧する)
- [x] `.`: 直前の変更を繰り返す
- [ ] `r<char>`: カーソル位置の文字を`<char>`に置き換える
- [ ] `shift+r`: 上書きモードに入る
- [x] `>>` / `<<`: 行を右 / 左にインデントする
- [ ] `=` / `==` / `=ap`: 範囲 / 1行 / 段落を自動インデントする
- `:retab`: タブと空白を`expandtab`の設定に合わせて振り直す
- [x] `shift+j`: 次の行を現在行の末尾に連結する
- [ ] `g` + `shift+j`: 空白を入れずに次の行を連結する(`shift+j`は空白を1つ入れる)
- [ ] `~`: 大文字と小文字を入れ替える
- [ ] `guu` / `g` + `shift+u`を2回: 行全体を小文字化 / 大文字化する
- [ ] `ctrl+a` / `ctrl+x`: カーソル位置の数値を1増やす / 減らす
- `gq`: 範囲を`textwidth`で折り返して整形する
- `:center` / `:left` / `:right`: 範囲を中央揃え / 左揃え / 右揃えにする

## オペレータとテキストオブジェクト

オペレータに、移動コマンドかテキストオブジェクトを続けて範囲を決める(`<操作><motion>` / `<操作><textobj>`)。
テキストオブジェクトはmodifier(`i`内側のみ / `a`周辺も含む)とobject select(対象を指定する文字)の組み合わせ。

- オペレータ
  - [x] `d`: 削除
  - [x] `c`: 変更(削除して挿入モード)
  - [x] `y`: コピー
  - [x] `>` / `<`: インデント
  - [ ] `=`: 自動インデント
  - [ ] `gu` / `gU`: 小文字化 / 大文字化
  - [ ] `g~`: 大文字小文字を反転
  - [ ] `gq` / `gw`: 整形(`gw`はカーソル位置を保つ)
  - [ ] `zf`: 折りたたみを作る
  - [ ] `!`: 外部コマンドに通す
- object select
  - [x] `w`: 単語(`a`は前後の空白を含む)
  - [x] `W`: WORD
  - [x] `"` / `'` / `` ` ``: 引用符
  - [x] `(` / `[` / `{` / `<`: 括弧
  - [ ] `t`: タグ
  - [ ] `s`: 文
  - [ ] `p`: 段落(`a`は後続の空行を含む)
- [x] `<operator><operator>`: `dd`のようにオペレータを2回打つと、その行単位に適用される。
- [ ] `<n><操作>`: 操作をn回分の範囲に適用する(`3dd`は3行削除)
- [ ] `gn`: 次の検索一致を選択する(`dgn`を`.`で繰り返すと一致箇所を1つずつ消せる)

## コピーと貼り付け

- [x] `y`: コピーする
- [x] `p` / `shift+p`: カーソルの後ろ / 前に貼り付ける
- [ ] `gp` / `g` + `shift+p`: 貼り付けて、貼り付けた末尾にカーソルを置く
- [ ] `]p` / `[p`: 現在行のインデントに合わせて後ろ / 前に貼り付ける
- [ ] `"<reg>y` / `"<reg>p`: レジスタ`<reg>`を指定してコピー / 貼り付ける
- [ ] `"0`: 直近のyank専用レジスタ(`d`で上書きされない)
- [ ] `"_`: ブラックホールレジスタ
- `"+y` / `"+p`: システムのクリップボードにコピー / から貼り付ける
- [ ] `:reg`: レジスタの中身を一覧する
- [ ] `:let @a = '...'`: レジスタの中身を直接書き換える

## visual mode

- [x] `v`: 文字単位で選択する
- [x] `shift+v`: 行単位で選択する
- [ ] `ctrl+v`: 矩形選択する
- [ ] `gv`: 直前の選択範囲を選び直す
- [ ] `o`: 選択範囲の反対側にカーソルを移す
- `g` + `ctrl+a`: 選択した数値を連番にする(1,1,1 → 1,2,3)

## 検索と置換

- [x] `/<pattern>` / `?<pattern>`: 前方 / 後方に検索する
- [x] `n` / `shift+n`: 次 / 前の検索結果に移動する
- [ ] `*` / `#`: カーソル位置の単語を前方 / 後方に検索する
- [x] `:noh`: 検索のハイライトを消す
- [ ] `:s/<before>/<after>/`: 置換する(構文: `:<range>s/<before>/<after>/<flags>`)
  - [ ] `<range>`: `%`でファイル全体、`'<,'>`で選択範囲、`5,10`のように行番号でも指定可(省略時は現在行)
  - flags
    - [ ] `g`: 範囲内のすべての一致を対象にする(無いと最初の一致だけ)
    - [ ] `c`: 1件ずつ確認しながら置換する
- [ ] `&`: 直前の置換をフラグ無しで現在行に繰り返す
- [ ] `:g` / `:v` + `/<pattern>/<cmd>`: 一致した / しなかった行それぞれに`<cmd>`を実行する(`:g/TODO/d`など)

パターンの記法:

- [ ] `\|`: いずれかに一致する(`foo\|bar`)
- [ ] `\<` / `\>`: 単語の境界に一致する
## 折りたたみ

- [ ] `zf<motion>`: 範囲を折りたたみとして作る
- [ ] `za`: 折りたたみを開閉する
- [ ] `zo` / `zc`: 折りたたみを開く / 閉じる
- [ ] `zR` / `zM`: すべて開く / すべて閉じる
- [ ] `zi`: 折りたたみ機能全体を有効 / 無効に切り替える
- [ ] `zj` / `zk`: 次 / 前の折りたたみに移動する
- [ ] `zv`: カーソル行が見えるところまで折りたたみを開く

## ファイル

- [x] `w`（write、保存）、`q`（quit、終了）、`a`（all）、`!`（強制）の組み合わせ。
      組み合わせは `:w` `:q` `:wq` `:wa` `:qa` `:wqa` の6通りに、`!`が最後に付くかどうかであり、12通り。
- [ ] `:x[a]`: 変更があるときだけ保存して終了する
      すでに条件付きの動作なので`!`は付かない
- [ ] `:e[!] <path>`（edit）: ファイルを開く。
      `<path>`省略時はカレントバッファ自体をディスクから読み込み直す動作になる。
      `!`でカレントバッファの保存していない変更を捨てて読み込み直す
- [ ] `gf`: カーソル位置のパスのファイルを開く
- [ ] `gx`: カーソル位置のURLやファイルを外部プログラム(ブラウザなど)で開く
- [ ] `:sav <path>`: 別名で保存し、そのファイルを開いた状態にする
- [ ] `:file` / `:file <path>`: 現在のファイル名を表示する / 変更する
- `:args`: 引数リストを一覧する(`:args <path>...`で設定する)
- `:next` / `:prev`: 引数リストの次 / 前のファイルに移動する
- `:mksession <file>`: ウィンドウ構成を保存する(`vim -S <file>`で復元する)
- [ ] `ctrl+z`: Vimを中断してシェルに戻る(`fg`で復帰する)

## バッファ

- [ ] `ctrl+^`: 直前のバッファ(alternate buffer)に切り替える
- [ ] `:bn` / `:bp`: 次 / 前のバッファに移動する
- [ ] `:ls`: バッファを一覧表示する
- [ ] `:b <n>`: n番のバッファに切り替える
- [ ] `:bd`: バッファを閉じる
- [ ] `:enew`: 無名の新規バッファを作って開く
- [ ] `:new` / `:vnew`: 分割してから無名の新規バッファを開く(横分割 / 縦分割)

## ウィンドウとタブ

ウィンドウ:

- [ ] `ctrl+w` + `s` / `v`: ウィンドウを水平 / 垂直に分割する
- [ ] `:sp` / `:vs`: 同じく分割する(`:vs <path>`で別のファイルを開きながら分割できる)
- [ ] `:new` / `:vnew`: 空のバッファで水平 / 垂直に分割する
- [x] `ctrl+w` + `h` / `j` / `k` / `l`: 左 / 下 / 上 / 右のウィンドウに移動する
- [ ] `ctrl+w` + `w`: 次のウィンドウに移動する
- [ ] `ctrl+w` + `c`: ウィンドウを閉じる
- [ ] `ctrl+w` + `o`: 現在のウィンドウだけ残して他を閉じる(`:only`も同じ)
- [ ] `ctrl+w` + `=`: ウィンドウの大きさを揃える
- `ctrl+w` + `+` / `-`: 高さを広げる / 狭める
- `ctrl+w` + `>` / `<`: 幅を広げる / 狭める
- [ ] `:res <n>` / `:vertical res <n>`: ウィンドウの高さ / 幅を指定する
- [ ] `ctrl+w` + `shift+` (`h` / `j` / `k` / `l`): ウィンドウを左 / 下 / 上 / 右に配置し直す
- [ ] `ctrl+w` + `x`: 隣のウィンドウと入れ替える
- `ctrl+w` + `r`: ウィンドウを回転する

タブ:

- [ ] `:tabnew`: タブを開く
- [ ] `ctrl+w` + `shift+t`: 現在のウィンドウをタブに切り出す
- [ ] `gt` / `gT`: 次 / 前のタブに移動する
- [ ] `<n>gt`: n番目のタブに移動する
- [ ] `:tabclose`: タブを閉じる
- [ ] `:tabmove`: タブを並べ替える
- [ ] `:tabdo`: 全タブでコマンドを実行する
