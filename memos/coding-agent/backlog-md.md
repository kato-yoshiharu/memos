# Backlog.md

## 概要

GitリポジトリのタスクをMarkdownで管理するCLIツール。
1タスク = 1つの `.md` ファイルで、リポジトリ内の `backlog/` などに置く。
Markdownファイルだけで完結する。

issueをgithub issueではなくgit管理したい場合に便利そう。
