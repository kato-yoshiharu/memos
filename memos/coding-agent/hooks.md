# hook

## hook とは

hook は、特定のイベントが起きたときに、`settings.json` やプラグインに登録したコマンドを実行する機能である。

代表的なイベント:

| イベント      | タイミング       | できること                 |
| :------------ | :--------------- | :------------------------- |
| `PreToolUse`  | ツール実行の直前 | 実行のブロック・許可判断   |
| `PostToolUse` | ツール実行の直後 | 結果の検査とフィードバック |
| `Stop`        | 応答の終了時     | 終了条件の検査             |
