# Window Manager

## AeroSpace

- ワークスペース、ウィンドウの切り替え
- ウィンドウサイズの調整
- タスクごとにワークスペースを割り当てることができる

### 基本的な使い方

- 起動/停止
  - `aerospace enable on` / `aerospace enable off`

キーバインド:

- ウィンドウ間のフォーカス移動: `alt + h/j/k/l`
- ウィンドウの移動: `alt + shift + h/j/k/l`
- レイアウト切り替え: `alt + /`（タイル）、`alt + ,`（アコーディオン）
- 前のワークスペースに戻る: `alt + tab`
- 次のモニターにワークスペースを移動: `alt + shift + tab`
