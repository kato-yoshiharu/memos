# CloudWatch Logs

## Overview

ログの階層は ロググループ > ログストリーム > ログイベント。

- ロググループ: 保持期間・暗号化・アクセス制御などの設定単位。
- ログストリーム: 同一ソース（コンテナ、Lambdaの実行環境など）のログの並び。
- ログイベント: 1行のログ（タイムスタンプ + メッセージ）。

## 保持期間

デフォルトは「失効しない（Never expire）」なので、指定しないとログが永久に溜まって課金され続ける。
必ず `retention_in_days` を設定する。

指定できる値は決まっている: 1, 3, 5, 7, 14, 30, 60, 90, 120, 150, 180, 365, 400, 545, 731, 1096, 1827, 2192, 2557, 2922, 3288, 3653。
