# S3

## Encryption

server side encryption: 暗号化と復号をS3に管理させる

aws:kms

## Upload to S3 Bucket

S3 Bucketにアップロードするaws-cliのコマンドは以下の通り。

```sh
aws s3 sync <directory> s3://<bucket-name>
```

## Terraformのstate置き場にする

S3をTerraformのstate backendにできる。
ロックはS3ネイティブの`use_lockfile = true`で足り、DynamoDBのテーブルは不要。
仕組みと経緯は [terraform/state.md](../infra/terraform/state.md) を参照。

```hcl
terraform {
  backend "s3" {
    bucket       = "<bucket-name>"
    key          = "<path>/terraform.tfstate"
    region       = "ap-northeast-1"
    encrypt      = true
    use_lockfile = true
  }
}
```

stateにはリソースの属性がそのまま入るため、DBの接続文字列や共有シークレットなどは**平文で保存される**。
`sensitive = true`はterraformの出力を伏せるだけで、state内は暗号化されない。

そのためstate用のバケットには以下を必須とする。

- パブリックアクセスを全てブロックする
- サーバーサイド暗号化を有効にする
- バージョニングを有効にする（壊れたstateから戻せるようにする）
