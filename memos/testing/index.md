# テスト

## テストで書くべきケースの種類

- 正常系: 典型的な入力に対して期待通りの出力になるか
- 異常系: エラーになるべきケースで期待通りな結果になるか
- 境界値: 数値の上限/下限ちょうど（0、-1、最大値、最大値+1など）、日付の月末/年末といった、条件式の`<`と`<=`を間違えると壊れるような値
- エッジケース: 特殊なケース。境界値はエッジケースの一種。
- 同値分割: 同じ結果になるはずの入力をグループ化し、各グループから代表値を1つ選んで冗長なテストを減らす考え方。
- 回帰テスト: 過去に実際に発生したバグの再現条件をテストとして残し、再発を防ぐ

## テストの観点

- 冪等性・副作用
- 非同期処理

全部を機械的に網羅するのではなく、対象の関数の性質（非同期か、副作用があるか、過去にバグが出た箇所か）や分岐の有無に応じて必要なものだけ選ぶ。
