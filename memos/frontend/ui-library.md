## ヘッドレスUIライブラリ

### ヘッドレスUIとは

見た目（スタイル）を持たず、**振る舞いとアクセシビリティだけ**を提供する UI ライブラリ。
Chakra UI や MUI のようなスタイル込みのコンポーネントライブラリと対比される。

提供されるのは主に次のもの。

- キーボード操作（Tab / 矢印キー / Esc / Home・End など）
- フォーカス管理（フォーカストラップ、閉じたときに開いた要素へ戻す）
- WAI-ARIA 属性（`role`、`aria-expanded`、`aria-controls` など）の付与
- 開閉やアクティブ項目といった状態管理

スタイルは利用側が当てるため、デザインシステムに合わせた見た目を作りつつ、
自前実装だと漏れやすいアクセシビリティ対応をライブラリに任せられる。

## Tailwind CSS + shadcn/ui（Radix UI）

### スタイリング: TailwindCSS

- Server Components はランタイムで CSS-in-JS を実行できないが、TailwindCSS はビルド時に CSS を生成するためこの制約を受けない。
- コーディングエージェントとの相性が非常に良い。
  - ユーティリティクラスが LLM の学習データに大量に含まれている
  - クラス名が自己記述的で CSS ファイルへの往復が不要

### UIコンポーネント: shadcn/ui + Radix UI

- shadcn/ui はコンポーネントのコードをプロジェクトにコピーして使う方式で、自社デザインシステムに合わせたカスタマイズが容易。
- 必要なコンポーネントのみを追加できるため、バンドルサイズを最小限に抑えられる。
