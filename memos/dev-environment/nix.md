# Nix

## Nix とは

宣言的で再現可能なパッケージマネージャ。
パッケージは Nix 式（専用の関数型言語）で記述し、同じ Nix 式を2回ビルドすると同じ結果になることを目指す。

パッケージは `/nix/store` 配下に、ビルド依存を含めたハッシュ付きのディレクトリとして置く（例: `/nix/store/b6gvzjyb2pg0kjfwrjmg1vfhh54ad73z-firefox-33.1/`）。
既存のパッケージを上書きせず、別のパスに新しいバージョンを追加する。
そのため、バージョンの共存、アップグレード途中の壊れた状態の回避、ロールバックができる。

multi-user インストールでは、一般ユーザーが他のユーザーに影響を与えずにパッケージをインストールできる。

## 関連用語

Nix まわりの用語:

- Nix: パッケージマネージャ本体
- nixpkgs: Nix のパッケージ定義の集合（NixOS のモジュールも含む）
- flakes: 依存と出力を定義する仕組み（`flake.nix`、`flake.lock`）
- NixOS: Nix と nixpkgs の上に作られた Linux ディストリビューション
- nix-darwin: NixOS の macOS 版にあたる、システム全体の宣言的設定
- home-manager: ユーザー単位のパッケージ・dotfiles の宣言的な管理
