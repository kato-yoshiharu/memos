# Data Modeling データモデリング

モデリングとは、現実の物事を抽象化すること。
システムの対象を(定まった記法で)図式化すること。

UMLとは、データモデリングの際に用いられる図の総称

開発工程によるデータモデリングの分類

- 概念モデル
  - 要件定義フェーズ
- 論理モデル
  - 基本設計フェーズ
- 物理モデル
  - 詳細設計フェーズ

フォーカス対象によるデータモデリングの分類

- コーポレートデータモデル
  - 全社レベル
- プロジェクトデータモデル
  - システム化領域レベル
